Getting started

Every request to the REST API goes over HTTPS. You sign it with a JWT that your IdP issues after SSO.

We store events in a Customer Data Platform (CDP), so the CDP can replay them for your SLA reports.

Ask the IT team before you add a new WSS to API_KEY.
